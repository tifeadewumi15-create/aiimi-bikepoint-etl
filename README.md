# Aiimi Data Engineer Technical Test — TfL BikePoint ETL

Client brief: the Mayor of London wants insight into TfL's BikePoint ("Boris Bikes")
network to inform decisions about where to invest in additional docking stations.

Source API: https://api.tfl.gov.uk/BikePoint/

## Structure
- `notebooks/` — Databricks notebooks (PySpark + SQL), exported here for version control
- `docs/` — thought process notes, architecture decisions, PowerPoint source material
- `data/raw/` — raw API pulls (sampled, for local reference only)
- `data/processed/` — cleaned/sample output for local reference
